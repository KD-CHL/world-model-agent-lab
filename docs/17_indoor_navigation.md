# G1 室内规划实验

## 场景与 agent

场景是程序化构建的 7.5 × 6 米室内物理仿真环境，包含四周墙体、中央操作台、货架、储物柜与绿色目标标记。障碍物使用实体碰撞几何，与导航地图共享同一组尺寸。它是静态、平地、已知地图实验场景，尚非真实房间扫描重建，也不包含视觉感知、动态行人或楼梯。

agent 每周期执行：

1. 读取 MuJoCo 底座观测，根据目标在 0.2 米网格上运行 A*。
2. 对障碍外扩 0.4 米，选择可直达的局部路点。
3. 世界模型展开候选动作序列，逐段检查线段与外扩障碍交集，排除碰撞路径。
4. 执行评分最佳序列的第一段，读取实测状态，更新残差反馈，再规划。
5. 连续十二周期位移不足 1.5 cm 时报告受阻；到达最终目标后返回交互输入。

MuJoCo 每个低层控制周期检查实际底座是否进入障碍预留间距，并保留原有姿态停止机制。圆形足迹与直线段预测是近似，不构成全身碰撞或真实机器人安全保证。

## 启动

```bash
cd /home/chl/GitHub/CodeSpace/world-model-agent-lab-main
conda activate wmal
export PYTHONPATH="$PWD/src"
python scripts/g1_agent_sim.py --config configs/g1_indoor.json
```

在 `goal>` 输入 `4 0`，机器人会绕开位于 `(2, 0)` 的操作台，到达另一侧。之后可输入 `0 0` 返回；输入 `quit` 退出。交互等待时暂停物理时间，窗口仍保留。带朝向约束的输入形式为 `4 0 90`，该约束未包含在本次绕障验收中。

自动化、无窗口验收：

```bash
python scripts/g1_agent_sim.py --config configs/g1_indoor.json --headless --goal '4 0'
```

自动目标模式结束后关闭会话；交互模式保留会话。失败返回非零退出码。事件记录在 `runs/g1_indoor/events.jsonl`，包括路径、路点、候选最优预测、残差、反馈比例、规划耗时和目标结果。

默认使用上一步已训练的 `runs/g1_research/model.json`。若不存在，先按 `16_g1_research_architecture.md` 采集并训练。

## 修改环境

`src/wmal/envs/indoor_scene.py` 的 `Box` 定义位置、水平半尺寸、高度和颜色；同一对象生成物理障碍与导航占据区域。编辑场景后应重新运行路径单测与仿真实验。

本次验证为单场景单目标冒烟实验；正式论文需要多个布局、目标、随机种子，以及无全局路由、无世界模型、无残差反馈等消融对照。路径规划目前使用已知地图，不能表述为视觉自主建图。
