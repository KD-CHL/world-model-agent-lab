# 研究问题与主线

H1：在固定技能控制器、候选集和交互预算下，经验证集校准的技能结果预测用于候选过滤与事件重规划，能提高受扰动组合任务的完成率。主要指标为扰动条件下整任务成功率，系统代价为约束；无提升或等预算反馈基线达到相同效果均可能否定该假设。未做外部新颖性检索。

| 路线 | 数据/目标 | 部分可观测性 | 成本与执行 | 接触操作及复现边界 |
|---|---|---|---|---|
| TD-MPC2（文献比较） | 仿真交互、奖励、技能 ID | 初期明确采用状态观测；视觉需历史/表征扩展 | 模型与价值联合训练，每控制周期有规划成本 | 接触转移需覆盖；先复现少量技能，不承诺论文水平 |
| Dreamer/DayDreamer | 序列、奖励、想象 actor–critic | RSSM 表达历史信念 | 训练含想象轨迹；执行 actor，无逐步 MPC 要求 | 可作后续替代；初期不并行复现 |
| DINO-WM | 离线动作图像轨迹、目标图像 | 历史特征输入 | 冻结视觉编码器，训练转移，执行优化动作 | 视觉目标需独立获取；预训练资源须披露 |

项目选择动作条件潜在动力学与技能控制作为功能主线，独立组织接口与实现，不预设为某篇论文的适配工程。上表只比较相关文献，算法组合及目标函数仍需评审。先解决状态下动作与技能接口，让高层贡献可归因。项目的技能 ID 对应有限任务嵌入，不是任意语言条件。技能表中语言仅映射到注册 ID；未知技能拒绝或返回不支持。

拟用单台七自由度机械臂与平行夹爪，具体资产及许可待实施核验；不沿用其他任务默认机器人。初期技能 reach/push/pick/place，实际可训练范围由基线验收决定。共享桌面任务：先移开挡路物、抓目标物、放入容器；采用同一连续场景，不在技能间重置。

额外引入技能结果模型，预测固定技能控制器执行后的相对物体位姿、结果谓词、耗时及完成标记。它是本项目新增的时间抽象世界模型，不归属于任何文献算法的原版组件。模型条件包含技能 ID、目标参数、初始状态、控制器版本及允许时长。用真实仿真技能轨迹监督，初期只做单技能候选评估，不把预测终态连续串接为任意深度搜索。

采用 bootstrap 集成预测结果，用独立校准集标定成功头；认知分歧、条件输出方差、执行残差分别记录。若标签不足或校准失败，只输出未校准分数并回退执行反馈，不输出伪成功概率。低层 Q ensemble 不提供动力学风险保证。

候选策略：先检查前置条件，再按语言相关性生成固定数目候选，以校准后的可执行性筛选，剩余候选按任务相关性和预计耗时排序。所有阈值从验证集选择，预算和选择规则锁定后测试。核心改进是可靠性门控；不同时增加多机器人、视频生成、端到端大模型微调。
