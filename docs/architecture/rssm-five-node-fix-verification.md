# 冻结 RSSM 五节点修复补验（2026-10-04）

## 已解除的功能限制

真实 MuJoCo，冻结 `visual-6218b8dd9f7ddb953a8f` 的检查点权重，A3完成
reach_A → hold_A → reach_B → hold_B → return_start。

## 根因与修复

1. 旧位置伺服没有重力前馈。B点零增量保持误差约 .058 rad；
   在命令容差球边界16个采样中最小稳态误差约 .0443 rad。
   临时关闭重力的诊断误差接近零，排除了目标写入错误；没有在正式实验关闭重力。
   新控制器每个物理 tick用零速度动力学计算重力项，通过位置执行器的仿射偏置前馈；
   PD与前馈合力共同经过原有forcerange限幅，不用无限幅qfrc_applied控制。
2. 旧候选重复固定增量，缺少精确到达与零增量稳定等待；新任务候选按剩余误差封顶。
   已知命令目标由真实当前命令加累计动作精确计算，作为技能进度/包络约束；
   RSSM的实测状态、RGB预测和误差界保持原始输出，不伪造为解析世界模型。
   在同等可执行命令进度候选中，仍按学习型物理后果排序；A3仍可拒绝全部候选。
   该单调命令约束适用于当前无障碍双关节技能，不适用于需绕行的通用运动规划。
3. 旧停滞指标仅看实测误差。修复为同时检查实测与命令误差，
   命令达容差后最多给予4个真实零动作采样的稳定宽限；真无进展仍有限失败。
4. 新控制器必须独立重新校准。完整旧关节范围数据所得误差界超过原可信度预算，
   A3以0动作拒绝执行；局部数据的标准差缩放校准仍在3步后拒绝。
   同一局部 calibration split 使用固定尺度残差校准（std_floor=1）后五节点通过。
   不是通过增大 error_budget 或删去坏样本得到通过；失败工件全部保留。
