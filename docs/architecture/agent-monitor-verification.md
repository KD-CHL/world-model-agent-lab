## 实施取舍与代价

1. 测试使用 `PYTHONPATH=src:tests` 或 discovery，而非不可导入的 `tests.test_*`；代价只是测试调用方式不同。
2. 技能包没有所引用的 task-start/task-done 辅助脚本，使用现有 brief、实际测试与手工进度记录；代价是进度记录自动化较少。
3. 图像使用 PNG 而非 JPEG，避免额外编码依赖并保留像素；代价是较大的帧传输量。
4. 实时服务由实验进程持有，而不是另建跨进程发布守护进程，Web 线程不访问 MuJoCo；代价是退出实验会关闭该实时服务，历史服务可独立重启。
5. 默认预览 320×240，而不是计划中的 640×480 示例，降低开销；代价是预览细节较少，模型输入不变。
6. 同目录命名 JSONL 各自列为独立来源，兼容训练 history 数组；代价是实验列表更长，不合并不同种子。
7. 按用户要求直接在当前 main 开发并普通推送，不新增 worktree/PR；代价是没有分支隔离，但保留了分阶段提交和可恢复的 Git 历史。
