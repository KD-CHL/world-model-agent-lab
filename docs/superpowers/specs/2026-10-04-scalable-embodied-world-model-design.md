# 可规模化具身世界模型与机器人闭环：架构规格

日期：2026-10-04。状态：用户已批准方向与预算，并明确要求计划完成后直接实施，免除再次确认。
本文件定义目标设计，不表示以下网络、分布式训练或新实验已经实现、通过。
现有代码基线为 `4e77231`，分支 `codex/rssm-five-node-fix`。

## 1. 目标、已确认约束与假设

用户确认：every-embodied 作为世界模型的方法和工程导航；DreamerV3 作为
训练网络机制参考；允许扩大模块数量，训练预算为约八张 RTX 3090。
主模型目标约 150M 参数，三个独立成员约 450M，另设约 300M 的容量对照。
目标是改善世界模型与机器人结合后的仿真规划，而不只是增加代码量或生成视频。

研究主线：世界模型预测候选动作后果；固定技能或低层控制器执行；高层 Agent
维护任务状态、组织计划、选择可接受的短动作段、根据真实反馈重新规划。
语言模型、VLA、记忆、低层控制器与世界模型不同时训练。
主论文问题是预测可信度是否帮助选择执行长度、识别预测失效和安排重规划。

环境统一为 `wmal`；本机用于小配置开发与仿真，服务器用于正式训练。
服务器暂按单机八卡、每卡 24GB 理解，不假设完整 NVLink 或已获得远程访问。
多机时复用语义与检查点格式，但拓扑、启动、通信性能需另行核验。
本规格不授权远程资源采购、长时间服务器训练、机器人真机动作、合并或推送。

## 3. 当前基线与不能跳过的事实

现有 categorical RSSM 已有 posterior/prior 分离、unimix、straight-through
表征采样、KL 梯度拆分、真实历史 burn-in、reset 与四路 episode 隔离。
已有开放环监督与预测/逐步反馈日志，应复用，不重复宣称为新增成果。

现有部署是 soft categorical probability proxy，不是随机轨迹的精确期望。
状态同时包含两维实测关节与两维指令；新设计须分离已知指令和未知物理后果。
现有模型按包含 free-nats KL 的总验证损失选模；新设计须另设预测验收与选模规则。

本机测试记录见 `docs/architecture/rssm-five-node-fix-verification.md`：
冻结模型在修复控制器及独立重新校准后可完成五节点，A1/A2 同样完成，
这证明闭环可运行，但不证明 A3 优于 A2。测试仅四条独立 episode，长时域覆盖
不足以认证目标覆盖率；全帧与动态区域预测均未整体胜过画面保持基线。
旧模型训练控制器与新测试控制器不同，架构比较必须消除此混淆。
现有 G1 是固定底座左肩 pitch/左肘双关节，不是完整抓取或全身控制实验。

## 4. 范围与阶段门槛

本次书面规格的交付范围是可规模化 RSSM、训练/推理协议及现有 G1 闭环适配。
扩展模块可配置，但按阶段加入，不能一次启用后把总收益归因给某个模块。

- 阶段一：新旧网络接口兼容、单视角物理状态/视觉预测、小配置训练、可信度
  协议及双关节真实闭环。保持当前任务成功条件与控制器不变。
- 阶段二：同一模型族的服务器配置、分布式训练、独立成员、严格恢复与性能报告。
  先测显存/吞吐，再决定正式训练规模；不以本机检查代替八卡实测。
- 阶段三：第二真实相机与技能结果标签按单独消融加入；扩展数据规模、失败场景，
  完成正式预测/规划研究评测。

物体位姿/接触分支只预留 schema 扩展点；真实物体控制技能、操作成功检测、
接触标签形成后另写子规格。因果 Transformer 动力学、视频扩散微调路线、
多尺度技能模型、在线适应、长期记忆及 LLM 改进不在本次实现范围。

## 5. 系统分层与数据流

```text
Task Agent：目标 / 已完成子目标 / 候选技能 / 最近反馈 / 失败原因 / 技能集合
    ↓ versioned candidate plans + immutable real observation context
World-model provider：编码 → posterior(h,z) → action-only prior rollout
    ↓ measured-state prediction / known commands / RGB / raw spread / validity
Independent calibration + selector：收益、误差预算、可执行约束 → 短执行段
    ↓ episode / step / decision / model / protocol bound commitment
Fixed controller → MuJoCo → each actual action endpoint observation
    ↓ aligned prediction residuals + receipt + true task verifier
Real history ledger + monitor → update task state → re-observe/replan
```

推理提供者不拥有执行、任务完成或修改控制器的权限。物理仿真是实际结果源，
不能用神经预测替代真实反馈来判定任务成功。生成帧不能写入真实观测账本。

Agent 只维护有界、连续、同一 episode 的真实历史；默认重新编码该历史，
不使用可变长隐藏记忆。候选分支从同一后验与同一随机数协议出发，相互隔离。
监控客户端保持只读；桌面窗口的任务结束不等于关闭整个会话。

## 6. 模块与网络职责

| 模块 | 输入与输出 | 第一阶段要求 |
| --- | --- | --- |
| 多视角视觉编码器 | 实际 RGB、相机 ID、有效掩码 → 视觉 tokens | 共享相机编码骨干；首版单视角，缺少全部视觉时按模式拒绝 |
| 本体状态编码器 | 具名实测状态、已知指令及有效掩码 → 状态 token | 不把缺失速度填成已测零速度；支持现有位置-only profile |
| 动作/技能条件编码器 | 具名动作、实际周期、版本化技能 ID → action token | 普通动作 profile 不要求技能标签；未知技能不得借用其他技能 ID |
| 多模态融合器 | 视觉/状态 tokens 与观测掩码 → posterior 条件 | 当前时刻模态融合，时序由 RSSM 维护；不用未来 token |
| 动作条件 RSSM | h、离散 z、action token、当前/下一已知指令 → prior(h,z) | 后验只能接受真实历史；分组 recurrent core、归一化与可配置容量 |
| 物理状态头 | h,z 与实测起点 → 逐时域物理状态残差 | 不把确定性指令当预测物理量；输出原始单位的可评价坐标 |
| 视觉变化解码器 | h,z 与当前真实图像条件 → 全帧预测 | 全帧与当前帧残差模式独立对照；不使用未来真图在线条件 |
| 技能结果头 | rollout 特征 → 进展/失败事件 logits | 无真实标签与 mask 时不训练、不发布概率、不参加规划评分 |
| 分布与校准适配器 | 多成员/多样本输出 → 均值、原始 spread、冻结误差界 | 明确推演模式、模型身份与校准适用范围 |

动作条件不仅在末端预测头注入；必须进入每次先验状态推进，
可通过同状态不同真实动作的配对验证其后果预测能力。
已知指令分支严格按执行协议在原始单位累加、检查包络；不静默 clip 动作。
这只适用于已声明的关节增量接口；绝对目标、力矩、开源数据动作需各自 profile。

真实 qvel、新相机或技能标签会改变观测/数据 profile，必须显式采集或验证转换。
在部署 profile 不支持对应观测时，禁用该分支而不是编造值。

## 7. 参数与计算预算

计数包括每个成员全部视觉骨干、融合器、RSSM、预测头和解码器的唯一参数，
分别报告 total/trainable/frozen，不把外部冻结 LLM 或重复引用权重混入计数。

| 配置 | 单成员目标范围 | 定位 |
| --- | --- | --- |
| WM-S | 30–50M | 小规模能力与容量对照，不保证适配所有本机批次 |
| WM-B | 120–180M，目标约150M | 正式研究主模型 |
| WM-L | 240–300M，单成员不超过300M | 独立容量对照 |

三个 WM-B 独立成员总量 360–540M，目标约450M；不是单个450M共享骨干。
成员按 episode bootstrap 与独立初始化训练；八卡顺序训练各成员，默认不并行
持有三套模型与优化器。成员推理可顺序进行，须报告累积耗时和峰值显存。
新provider允许真实单成员实验，不能复制同一成员伪造集合；现有legacy接口的
至少两成员要求保持不变。单成员只可使用固定尺度残差校准，集合缩放模式明确
拒绝不足成员；单成员内多样本与多成员集合分别报告，不能混淆。
用于协议测试的更小 smoke 配置明确标注，不冒称 WM-S/B 的效果。

容量由编码通道、fusion 宽度、recurrent state/MLP 宽度、latent 大小与 decoder
宽度配置；正式配置通过实际构建计数检查目标范围。不得添加无参与前向的参数
凑数。实施计划需给出具体维度及静态计数，实际训练前再复核资源占用。

服务器初始探测：128×128，单相机，32个观测/31个连接动作的训练序列，
最多8步真实历史，预测H=8；每卡 microbatch=2，8卡、累积4，有效批次64序列。
训练起点在连续真实序列中抽取，每个未来 target 均有对应真实动作；不足8步的
启动历史以 mask/reset 表达，不能跨 episode 补齐。32观测序列的有效起点索引为
0..23（H=8），每个起点只取最近最多9个真实观测，不能将整段早期carry作为
额外在线记忆。其余观测只服务各起点的监督；H=16另用配置、训练和校准。

混合精度以硬件/安装版本探测为前提；log-prob/KL、统计与校准维持FP32以上必要
精度。先 DDP，激活检查点、梯度累积，再按实测切换 FSDP。
正式初始配置目标为每卡allocated/reserved峰值均不超过启动时报告总显存的80%，
预留20%运行余量；不能只算权重。完整更新探测失败则记录失败、显式调整配置
重新探测，不静默减少序列、视角或批次。性能结论绑定最终实际配置。
八卡验收报告峰值allocated/reserved、步吞吐、数据等待、通信时间、序列长度、
视角数和精度。不承诺固定训练时长，不把150M参数量当作可训练性能证明。

## 8. 训练目标、选模与冻结规则

基本训练目标：后验观测重构 + 多步先验物理状态残差 + 先验画面预测
以及 dynamics KL、representation KL、有真实标签时的 masked event loss。
保留 free nats、unimix 和分离停止梯度，不从零重新发明已有机制。

物理状态监督只覆盖实际测量维度；已知指令损失不计入物理预测成绩。
画面损失拆成全帧项和变化区域项，两者分别按有效像素归一化。
动态区域由真实训练/验证 target 差异构造，只作损失/评测 mask，不作为未来输入。
没有变化像素时区域项不虚构误差；记录有效像素数与适用样本数。
训练数据增强同一序列时序一致，不改变关节/相机标签语义；评测固定。

后验可观察训练序列的真实后续帧来计算表征损失，但候选 prior 路径仅从预测起点
以前的历史构造状态，未来真帧不进入 prior。burn-in/padding 不作 future target。
多步 latent consistency、学习方差/NLL、SIGReg 不是首版默认叠加项。

记录原始与截断 KL、截断比例、prior/post entropy、latent 使用统计、各损失与
梯度范数、逐时域物理误差和画面保持基线。KL接近floor不能直接断言表征崩溃。

默认选模采用验证集“逐维训练尺度归一化的物理状态RMSE在H1..H8的均值”最小；
图像误差、动态区域误差与各时域原始单位结果同时报告，不用它们隐藏状态退化。
等分时选更早epoch；精度/采样协议在整次训练中固定。总目标损失保留诊断，但不
单独决定部署检查点。新任务改变选模规则时建立新实验，不回看test修改规则。

步骤顺序：训练基础世界模型 → 冻结选定检查点与推演协议 → 独立校准 → 最终评测。
微调只更新声明的世界模型参数。冻结编码器是可选消融，须检查张量未变化。
结构不相同的旧模型不支持静默全量微调；仅显式迁移名称/形状/语义均匹配的层，
报告迁移、随机初始化与冻结清单。随机新网络继续学习不称为开源预训练微调。

## 9. 数据、来源与无泄漏

episode 包含对齐真实RGB、具名物理状态、known commands、实际动作、时间点/
控制周期、相机描述与可选真实技能/event标签，明确T观测与T-1动作关系。
新schema与旧 `visual_episodes.v1` 通过显式适配器互通，旧文件只读。
控制器、场景、相机、初始状态、采集策略、数据revision/许可进入manifest。

划分以原始episode为单位；同一episode的不同相机、裁剪、重导出及派生窗口必须
同split。记录来源ID与原始内容hash，不能靠改变压缩格式或文件名躲避泄漏检查。
训练拟合归一化；validation只选模型；calibration只拟合误差界；test最后评测。
微调继承祖先训练/选模暴露清单，新校准或test不能与任何祖先暴露轨迹重叠。

当前40episode/640转移只用于 smoke 或历史诊断，不支持150M性能结论。
扩展采集覆盖正反动作、保持、不同速度响应/初态、目标距离及可控失败；控制器
参数固定。首次正式评测协议至少保留100条独立calibration和100条独立test轨迹，
这是操作性下限，不是覆盖率认证或充分训练数据量证明。train规模按学习曲线决定。
闭环评测另设未用于离线选模/校准的任务初态与扰动种子。

开源LeRobot/Unitree数据经既有转换链保留动作维度、单位、频率和相机；
不把16维真机操作数据强行当2维G1增量。profile不同先离线训练/评测，只有映射、
固定技能、真实反馈语义验证后才在线调用。无动作视频不能冒充动作后果监督。
raw/processed/checkpoints/runs均在项目约定且Git排除的路径，代码不包含大资产。
跨任务混合按配置中的任务/机器人/profile/技能或事件采样权重记录；不直接混合
不可比较动作坐标。默认先均匀抽episode再抽有效起点，避免长episode以窗口数
支配训练。暴露次数、实际任务比例和稀缺标签比例进入训练报告。

## 10. 推理与可信度协议

新协议命名 `wmal.embodied_prediction.v1`，旧模型通过显式legacy适配器保留旧
版本、哈希、行为与校准；不会偷偷替换当前演示模型。

请求必须携带：request/decision ID、task/node ID、episode/末端step ID、context
step IDs、真实时间、观测profile、action profile、controller profile/hash、模型
与推演协议版本、候选ID/技能版本、展开后动作序列及预测H。
请求额外含run ID、不可变观测内容hash、候选动作内容hash、客户端截止期限与
传输超时预算；不能仅靠可重复使用的step ID或candidate ID绑定实际内容。
历史间动作须已执行；序列必须连续且对齐。缺失必要观测、超训练H、单位/周期/
控制器不匹配、实际值越适用范围在调用前拒绝。缺失相机不自动切换已校准模式。

响应回显请求身份、内容hash与起点，返回：

- `physical_states`：成员/样本/H/具名物理维度，与确定性指令分开。
- `known_commands`：每H步具名指令；已有维度若需给legacy消费者合并必须标记来源。
- `frames`：按相机ID的成员/样本/H/CHW float [0,1]，或明确的未请求状态；
  缺图不伪造零图。监控显示转换为HWC uint8，格式转换不改变预测评价坐标。
- 模型与推演版本、维度/单位、有效掩码、拒绝原因、事件监督可用性。
- 成员内采样差异、成员均值间差异、posterior/prior诊断与实际推理耗时。

新模型默认对后验及先验使用有seed的categorical采样；每成员默认8条轨迹。
固定历史/模型时，同一决策的候选共享相同按成员/样本/步索引的随机数，不依赖
候选遍历次序，也不共享可变carry。协议记录seed推导规则、样本数、dtype、
normalization、相机/状态/动作profile与模型内容hash。seed按决策来源可复现。
旧soft代理作为独立对照模式，不混用其校准；更改模式或样本数须重新校准。

组间/组内方差只是诊断，不自动等于认识/偶然不确定性的真实分解。
校准默认用固定训练尺度物理残差；ensemble缩放是另一个冻结对照。
calibration绑定模型、推演协议、controller、观测/动作profile、时域与部署scope；
确定性指令不占用物理误差预算。若期望同时覆盖多个时域，使用episode内
跨维度、跨窗口、跨前缀的最大残差构造统一score，不把逐H边际覆盖冒称联合覆盖。
报告覆盖与区间宽度、样本数和区间估计；样本不足则拒绝出具有限声明。
可交换性是条件，闭环自适应与分布偏移下不能自动推广为安全或覆盖保证。

## 11. Agent、远程服务与持续仿真

选择器先验证真实状态及known-command的技能约束，再比较预测物理收益和
校准误差界。现有单调关节命令约束只用于当前无障碍技能，不能泛化到绕障任务。
A0固定计划、A1反馈/名义后果、A2学习型预测排序、A3校准前缀；技能集合、
候选预算、controller、任务容差、恢复次数、真实历史范围均在对照中固定。
先在R0无恢复配置比较A0–A3，再固定恢复策略比较相应R1；恢复机制另作消融，
避免把恢复预算变化当作世界模型收益。初态/扰动种子配对，记录全部失败。

预测mean/bounds不能取代真实成功检测。执行每一步都回传真实端点，计算
逐维残差、首次超界步、RGB差异、动作耗时与重新规划原因；更新状态后再计划。
没有可接受候选时给出有限拒绝/needs_review，不能自动用未校准解析模型顶替。

提供本地provider与可选服务器provider，协议一致；服务器只推理，不接受机器人
执行请求。远程提供者默认仅绑定本机接口，跨机使用显式配置与认证，不写密钥
到日志。规定超时、取消和响应尺寸上限，禁止网络等待时无限执行上次动作。
实际调用必须有可生效的传输/工作进程超时边界，不能只在同步函数返回后检查
用时。截止期限由客户端自己的单调时钟判定；跨机不比较单调时钟绝对值。
派发前再次核对观测/历史与版本。校准工件由客户端校验和绑定，不盲目信任
服务器自称的成功概率或误差界。
超时或缺反馈时清空尚未派发前缀并锁止自动派发，保留诊断；不得盲目重发动作。
晚到/重复/起点改变/版本不符的响应丢弃，reset使所有旧episode请求失效。

持久窗口在任务成功/失败后保持可观察与可显式reset；没有新动作时按固定控制器
规定保持。若等待期间继续推进物理，必须更新step/时间并重新观测，不能使用过时
状态响应发动作。逐步反馈缺失的session沿用已有故障锁止规则。
真实MuJoCo画面是验收内容，实时浏览器画面可选；不要求开发新的机器人操作UI。

monitor复用现有事件链，显示任务/子目标、候选比较、预测与真实差异、可信前缀、
拒绝/恢复原因、模型/校准版本和耗时。训练输出另有分项损失、选模指标、进度、
显存/吞吐报告；画面好看或损失下降不代替任务指标。

## 12. 分布式工程与检查点

统一配置定义模型、数据profile、采样、训练、选模、distributed与logging；
启动前校验shape、world_size、microbatch/累积有效批次、数据来源和非空输出目录。
成员episode bootstrap在所有rank上保持一致后再分片；随机窗口可在epoch间重复，
但必须记录实际样本数和分片/尾批处理策略。validation按唯一sample ID聚合，
禁止因分布式补齐重复项改变选模权重。

优化器/AMP/scheduler、所有rank的随机状态、epoch/全局step、采样位置与数据hash
进入恢复检查点。声明精确恢复时必须同world_size/配置/数据和运行版本；变化时
显式作为非精确继续学习，不沿用精确恢复声明。恢复点在完整优化器步边界。
推理checkpoint与训练resume checkpoint分开；原子写入，失败不覆盖有效模型。
rank失败不报告成功；聚合日志不重复epoch进度。保留运行配置、依赖版本、
模型/数据/控制器hash和服务器硬件/拓扑报告。

## 13. 验收：功能与研究效果分开

### 必须通过的工程验收

1. 所有旧回归继续通过；旧模型/校准身份与演示行为不因新schema改变。
2. 未来真帧不可影响候选prior；padding/reset、候选分支隔离、seed可复现及候选
   顺序不变性通过；物理/known-command分支来源可检查。
3. 无标签不输出事件概率；相机、动作单位、周期、控制器、版本、scope或H
   不匹配明确拒绝；输入NaN、超时、晚到、reset、部分反馈失败不派发后续动作。
4. 用真实数据完成smoke训练、验证选模、保存/加载、声明范围内的精确恢复、
   独立校准与评测；数据/祖先暴露和派生视角无泄漏。
5. 真实MuJoCo五节点及重复reset仍通过，原成功标准不降低；窗口保持与quit
   路径均验证。物体操作未就绪时不报告stack/clean/pour成功。
6. 参数计数与预算检查通过；本机单卡训练/推理测得显存与吞吐；正式八卡
   有资源时再验DDP/FSDP数值/聚合/恢复与资源占用。资源未到位明确标为未验证。

### 研究结果验收与不保证项

同新controller、同split与计算协议重训旧网络对照；保留当前冻结旧模型作历史
对照，不能只用控制器迁移样本声称网络提升。至少报告：

- H1..H8逐维物理RMSE、状态保持与训练集拟合的简单动力学基线；多步累积漂移。
- 全帧/变化区域MSE与保持图像基线；state-only与RGB+state消融，固定相同
  known-command与残差起点。当前残差头读取实测起点，不能冒称纯vision-only；
  无本体输入的纯视觉任务需另立观测/输出profile，不在首版验收范围。
- 真动作/zero-action/乱序动作对照：同目标下更低误差才是有用动作条件证据；
  敏感性非零不等于准确。若有配对仿真分支，记录其真实counterfactual结果。
- 校准覆盖/宽度、拒绝率、适用scope内外、不同前缀、闭环残差；样本置信区间。
- A0–A3任务成功/恢复/不可恢复失败、执行段长、动作次数、模型调用与规划耗时。
- WM-S/B/L容量对照与单成员/多成员成本；全帧/残差decoder、采样/soft模式分开消融。

预注册目标是状态多步平均误差与动态区域画面误差优于相应持久性对照，且A3在
固定扰动任务上减少失败或在匹配成功率下减少风险暴露；这不是交付保证。
若未达到，保留负结果并报告性能限制，不能放宽阈值、缩小test、改成功检测来
制造通过。对可检测分布外输入的拒绝与范围内性能分别报告。
先锁定训练/选模/校准配置，再运行未触碰的最终test；论文收益以多种子独立任务
和区间估计为依据，不以一次五节点成功或参数量当作创新证据。
