## 预算估计方法

硬件工作假设：Ubuntu工作站、一张可用GPU、足够存储；型号/显存/驱动未知，不指定已验证版本。先做1个任务1个种子的1000步采样与100次更新计时，记录峰值显存、每步存储与训练吞吐。

单方法训练时间估计 = 环境交互数/有效采样吞吐 + 更新数/更新吞吐（分时方案）；异步方案以实测并发吞吐计算，不能直接相加后再声称并发收益。总GPU小时按方法×种子×配置计并加入预实验/失败重跑预算。数据量 = 控制步数×每步字节 + 视频；Agent成本 = 调用数×实际输入输出计费或本地推理时间。先完成容量测量再锁定步数与正式预算。

M0/M1可先CPU调试；不承诺CPU可完成研究训练。Ubuntu版本、Python、MuJoCo、PyTorch及CUDA组合在安装前查官方兼容性并锁定；本骨架不提供伪造依赖锁。
