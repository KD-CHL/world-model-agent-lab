# 训练、执行与评估伪代码（不是可执行算法）

## A. 采样与低层学习
```text
划分场景/对象/回合组，锁定 test；初始化有限技能及奖励定义
for 每个训练回合:
    reset(train配置, seed)
    固定本回合 controller_version
    while 未终止:
        用当前技能嵌入和状态进行 潜在动力学控制 短视野规划
        校验并执行首个动作，记录实际动作而非计划动作
        将 (obs, action, reward, next_obs, terminated, truncated, skill_id) 写入仿真回放
        按配置 update/data 比率采样连续序列
        更新 encoder/dynamics/reward/Q：潜在一致性 + 奖励预测 + TD价值目标
        更新策略先验；目标网络按原算法EMA更新
    保存技能片段与独立结果标签
```

上述损失与更新流程是待评审的设计提案，不绑定特定论文实现。实现时独立定义各模块接口、目标函数与梯度路径，并为所借鉴的方法保留出处。世界模型损失更新编码、转移与预测头；策略模块采用独立参数更新；Agent 无反向传播。EMA、价值目标与更新比率均需单独验证，不能仅凭名称声称复现或创新。

## B. 技能结果模型
```text
先冻结低层技能控制器，收集各技能/目标/初态的完整执行结果（含失败）
按回合及场景分组划分 train、calibration、validation、test
对每个 ensemble 成员进行按回合 bootstrap，而非独立打散帧
训练 (状态,技能,目标,时长限制,控制器版本) -> 终态/结果谓词/耗时分布
损失 = 标准化终态回归或NLL + 成功标签BCE + 耗时回归
各权重仅在validation选择；calibration仅拟合概率校准变换
固定技能模型；在validation选择可靠性门控阈值与恢复规则
```

结果标签包括结束时物体相对位姿、成功标记、时长、超时及截断；被中断技能保留 censor 标记，不把未观察到的终态当失败终态回归。新增模型不与 潜在动力学控制 联合反传。新增成本为技能标签采集与 K 个轻量结果预测器训练；K 初设5作预算估计，需和1成员对照。控制器更新后旧结果模型不能直接套用，必须重新验证/再校准。

初期技能层只评估单个技能，因此不要求从低层潜在状态解码物理终态；这是选择独立结果模型而非直接调用 潜在动力学控制 rollout 的原因。验证同一候选初态的预测终态/成功排序与实际执行一致性，并记录 OOD 初态。失败时回退普通执行反馈 Agent。

## C. Agent 与重规划
```text
读取任务、允许技能与最新有效观测
生成候选并校验前置条件；固定候选数与调用预算
对候选请求结果预测；失效/版本不匹配则不用该预测
按可靠性门控筛选，再按相关性与预计代价选择
执行技能，逐控制步记录预测残差及环境事件
若前置条件失效/残差事件/超时：停止当前技能，刷新观测，有限次恢复
独立检测器确认技能及整任务结果；达到预算时明确失败/截断
```

固定周期与事件触发对照使用相同最大规划调用预算。每技能最多2次重试、每任务最多4次恢复作为初始提案，验证后锁定。整技能终态预测不能与中间帧直接做残差：初期以结果谓词与终态核验为主；中间残差由另行定义的低层一步状态预测或阶段检查提供。未实现该状态预测时禁用对应事件。

## D. 独立评估与恢复
```text
从预注册协议加载测试场景、种子、预算、固定快照
禁止训练/校准/阈值选择；所有变体使用配对初态与扰动计划
运行全部回合（含超时/中断）；记录进程错误与实验失败两类状态
先按训练种子聚合，再计算跨种子区间；导出原始表和图表
```

检查点含模型、优化器、EMA、调度器、训练步、RNG、回放索引/数据manifest及配置哈希。训练恢复需验证这些字段，不能只载网络权重后称完全续训。在线适应独立协议限制可更新模块、数据来源和步数，禁止将其与冻结测试混报。

主线暂不使用模型生成轨迹训练技能结果模型。数据 provenance 分为 sim_interaction、model_imagination、expert_demo；recovery 是阶段标记，避免恢复样本与仿真来源重复计数。后续若引入 模型生成的合成数据，需独立数据混合和 rollout 长度实验。
